# 练记 DAYFORM

个人健身记录 PWA。React + TypeScript + Vite，数据和压缩后的餐食照片保存在浏览器 IndexedDB。

## 本地运行

```sh
npm install
npm run dev
```

以终端显示的地址打开。开发服务默认监听局域网，可用同一 Wi-Fi 下的手机访问电脑 IP；PWA 安装和离线缓存需要 HTTPS 或 localhost。

## 构建与预览

```sh
npm run build
npm run preview
```

离线 Service Worker 只在生产构建中启用。第一次在线访问并完成缓存后，才可离线打开。

## 验证

```sh
npm run build
npx playwright install chromium
npm test
```

端到端检查覆盖饮食照片、逐组训练、老师要点、刷新持久化、备份恢复、无效备份、示例隔离、手机布局和离线使用。测试会启动本地生产预览。

## 功能

- 按日期记录，支持历史补记、月历和每日汇总。
- 早餐、午餐、晚餐、加餐，支持文字、照片、时间；照片自动缩放到最长边 1280 px。
- 快捷饮水、自定义容量、撤销、明细删除、个人目标。
- 力量训练逐组记录重量和次数、自重训练、复制上一组、上次数据引用；有氧时长和距离。
- 休息日、训练完成状态、每日感受。
- 老师要点、动作关联、重点标记、动作库搜索与部位筛选。
- 本机自动保存、包含照片的 JSON 导出、经过结构校验和确认的完整备份恢复。
- 独立示例预览，示例不会写入个人记录。

## 数据与隐私

尚未接入云端账号和同步，也不会上传任何记录或照片。不同浏览器、端口和域名有独立的数据空间。更换地址或设备前，先导出备份，再在新地址导入。隐私模式、本机磁盘空间不足或清理浏览器数据可能影响数据保留。建议定期导出，照片随完整备份一起保存。餐食和要点表单的文字草稿保存在当前会话中，照片需点击保存后才写入日志。

## GitHub Pages

仓库内已提供 `.github/workflows/deploy.yml`。将本目录作为独立仓库根目录推送到 GitHub，将仓库 Pages 的 Source 设置为 GitHub Actions，推送到 main 分支后自动发布 `dist/`。Vite 使用相对资源路径，兼容仓库子路径。公开仓库不要提交个人导出文件。

## 后续云端接入

持久化入口集中在 `src/storage.ts`，业务结构位于 `src/model.ts`。云同步仍需实现身份验证、每条记录的更新时间/删除标记、图片上传、权限及冲突处理，不能仅替换存储地址。
